Crest Water 4 direct-port notice
================================

Reference repository:
  https://github.com/wave-harmonic/crest

Reference commit:
  db0658ff0b2e93e4a9e28cc2867509658b0ecc00

Directly ported source/algorithms in this Stage C package:

1. crest/Assets/Crest/Crest/Scripts/OceanBuilder.cs
   - PatchType topology set
   - BuildOceanPatch mesh construction
   - CreateLOD 16-tile LOD0 / 12-tile ring layout
   - fat/slim patch assignment
   - outer horizon skirt behavior
   - patch orientation rules

2. crest/Assets/Crest/Crest/Shaders/OceanVertHelpers.hlsl
   - ComputeLodAlpha
   - SnapAndTransitionVertLayout
   - 2x geometry-grid snapping
   - 4x geometry-grid topology morph
   - minRadius = 0.375

3. crest/Assets/Crest/Crest/Scripts/OceanRenderer.cs
   - baseMeshDensity relation
   - _lodAlphaBlackPointFade calculation
   - _lodAlphaBlackPointWhitePointFade calculation

Unity-specific GameObject/Renderer/CommandBuffer plumbing is not copied. It is replaced by
Godot Node3D / MeshInstance3D / ShaderMaterial orchestration while preserving the above
Crest topology and shader math.
